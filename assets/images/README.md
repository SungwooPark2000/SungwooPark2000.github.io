# Image files

Add the following files without changing their names. The website shows a clean
placeholder until each image is added.

## Profile

- `profile.jpg` — recommended portrait ratio: 4:5, at least 880 x 1100 px

## Publications

- `publications/risk-based-airspace-capacity.jpg`
- `publications/decentralized-utm.jpg`
- `publications/multilateral-negotiation.jpg`
- `publications/airport-control-zone.jpg`
- `publications/ground-risk-analysis.jpg`

Recommended publication image ratio: 3:2, at least 1140 x 760 px.

## Projects

- `projects/decentralized-traffic-management.jpg`
- `projects/urban-drone-delivery-network.jpg`

Recommended project image ratio: 16:9, at least 1280 x 720 px.

JPG, PNG, and WebP are all supported, but the filename extension in `index.html`
must match the uploaded file. Keep each image below approximately 1 MB for faster
page loading.
