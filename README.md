# Sungwoo Park Academic Homepage

This folder is ready for a GitHub Pages user site.

## Upload

1. Copy all files and folders in this directory to the root of the
   `sungwoopark2000.github.io` repository.
2. Keep `index.html`, `cv.pdf`, and the `assets` folder at the repository root.
3. Add the image files listed in `assets/images/README.md`.
4. Commit and push the files. GitHub Pages will update automatically after the
   deployment finishes.
